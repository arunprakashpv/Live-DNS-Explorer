Live DNS Explorer

Query real DNS from your browser using DNS-over-HTTPS APIs.

What is Live DNS Explorer?

Live DNS Explorer is a fast, entirely client-side web application designed to help developers, sysadmins, and curious minds query the Domain Name System (DNS) in real-time. It mimics the experience of a terminal utility while providing a beautiful and responsive user interface.

How does it work?

Unlike traditional DNS tools that run locally or require backend servers to proxy your requests, Live DNS Explorer runs entirely in your web browser. It achieves this by using DNS-over-HTTPS (DoH).

DoH is a protocol that performs remote DNS resolution over the standard secure HTTPS protocol (port 443). The application formats your lookup request and sends it securely to public DNS resolvers equipped with RESTful DoH endpoints, such as:

  • Cloudflare (1.1.1.1): Known for its privacy-first approach and extreme speeds.
  • Google (8.8.8.8): A highly reliable and globally distributed public DNS service.

Once the resolver looks up the domain records across the global DNS network, it sends the response back to your browser as a JSON payload. Live DNS Explorer then parses this JSON and presents it beautifully in the simulated terminal.

Supported Record Types

The tool allows you to query various standard DNS record types to inspect the health and routing of a domain:

  • A (IPv4 Address): Maps a domain to its physical IPv4 address.
  • AAAA (IPv6 Address): Maps a domain to its physical IPv6 address.
  • CNAME (Canonical Name): Aliases one domain name to another.
  • MX (Mail Exchange): Directs emails to the correct mail server for a domain.
  • TXT (Text): Holds arbitrary text, heavily used for email verification (SPF, DKIM, DMARC) and domain ownership checks.
  • NS (Name Server): Indicates which DNS servers are authoritative for the domain.
  • SOA (Start of Authority): Contains administrative information about the DNS zone, such as the primary nameserver and TTLs.
  • PTR (Pointer): Used for reverse DNS lookups (resolving an IP address back to a hostname).

Privacy

Because the app communicates directly with Cloudflare and Google from your browser, no DNS query data is ever sent to or logged by the creator of this tool. Your traffic remains between your device and the chosen resolver.
